# 抖音 / TikTok 账号监控

挂机盯多个账号：发新作品自动下载、开播自动录屏、历史作品自动核账补齐。

原生 Tkinter 桌面程序，无浏览器依赖；打包后是单个 `抖音监控.exe` + `_internal` 目录，免安装。

---

## 一、下载与运行

### 方式 1：用打包好的 EXE（推荐）

1. 打开 [Releases](https://github.com/xxxqTvT/douyin-monitor/releases) 下载 `douyin-monitor_v*_windows_x64.zip`
2. 解压到任意**普通目录**（不要放 `C:\Program Files`，会没有写权限）
3. 双击 `抖音监控.exe`

免安装、不写注册表；除了「开机自启」会在注册表 `Run` 下加一项（可随时关掉）。

### 方式 2：从源码跑

需要 Windows + Python 3.12（Tkinter 随 Python 自带，无需第三方库）：

```bat
python douyin_client.py
```

### 方式 3：自己打包

```bat
pip install pyinstaller
python build_app.py
```

产物：`dist\抖音监控\抖音监控.exe` 与 `_internal\`，把整个目录拷走即可用。

## 二、第一次使用

### 1. 登录

设置 → 账号与登录 → **抖音扫码登录…**

- 弹出浏览器窗口，用抖音 App 扫码
- 成功后 Cookie 自动写入 `data\Volume\settings.json`
- TikTok 需先配代理：设置 → 账号与登录 → TikTok 代理…

登录态过期时，状态列会提示「出错：Cookie 失效」，重新扫码即可。

### 2. 添加账号

设置 → 账号与登录 → **添加账号…**，三种输入都支持：

- 抖音号，例如 `92897238244`
- 主页链接，例如 `https://www.douyin.com/user/MS4wLjABAAAA...`
- 分享短链，例如 `https://v.douyin.com/xxxxxxx/`（自动解析）

### 3. 开始监控

点底部 **开始监控**。也可以设置 → 监控与通知 → **启动软件后自动开始监控**，之后开程序就自动跑。

## 三、界面说明

### 账号列表

| 列 | 含义 |
|---|---|
| 平台 | 抖音 / TikTok |
| 昵称 | 鼠标悬停显示抖音号 |
| 状态 | 监控中 / 直播中 / 刷新中 / 出错 / 待监控 / 已暂停 |
| 监控 | 直播中的圆点 + 该账号监控内容（作品+直播 / 作品 / 直播 / 跟全局） |
| 刷新 | 单独查这个账号（直播 + 新作品） |
| 保存位置 | 默认，或自定义文件夹末级名（点一下打开） |
| 最近检查 | 上次检查时间 |

**状态颜色**：绿=监控中，红=直播中，蓝=刷新中，橙=出错/限流，灰=未启用/待监控。

**操作**：

- 单击「刷新」列 → 只查这个账号
- 双击整行 → 打开主页
- 右键 → 刷新 / 核账 / 下载历史 / 设保存位置 / 暂停 / 删除 / 监控内容四选

### 右侧三个面板

| 面板 | 内容 |
|---|---|
| 直播录制 | 正在录的场次、画质、时长、大小；可「开始/停止」单个账号 |
| 本次下载 | 本次真正落盘的作品，点行可打开文件或所在目录 |
| 运行动态 | 日志；只看警告可勾「只看警告」 |

面板右上 `×` 可收起，之后自动出现也不会弹回；设置 → 界面与窗口 里能重新显示。

### 底部控制区

- 检查间隔（秒）：作品轮询周期，默认 1800
- 直播间隔（秒）：独立直播轮询周期
- 全量核账（分，0=不全量）：多久做一次全量核账，默认 1440
- 检测直播：总开关
- 监控内容：作品和直播 / 只监控作品 / 只监控直播
- 启动后自动监控先全量核账：慢一次，但能兜住隐藏后放出的作品

## 四、下载与文件组织

### 保存位置

- 默认 `data\Volume\Download`
- 「下载历史视频」与核账补下的作品，统一进 `data\Volume\历史下载\`
- 每个账号一个目录，命名 `UID<抖音号>_<昵称>_发布作品`

### 同名与重复

- 已存在的文件不会重下，只补下载记录
- 同一作品图集必须**所有图都在**才算下过，缺图会补齐
- 画质取接口最高档：优先按分辨率，其次码率

### 单独下载

设置 → 下载 → **单独下载链接…**，粘贴一条或多条分享链接，落到默认下载目录。

## 五、核账（历史作品补齐）

| 触发 | 行为 |
|---|---|
| 每轮检查 | 默认只核对上次水位之后的作品（增量） |
| 到全量间隔 | 从最新翻到最旧，全量比对（防隐藏作品放出后漏掉） |
| 菜单「核账全部历史作品…」 | 立刻全量，只报告缺什么，不下载 |
| 账号右键「核账历史作品」 | 同上，仅该账号 |

判定规则：本地文件齐全 → 不下载；缺文件 → 下载；文件在但没记录 → 只补记录，不重复下载。

同一时刻只允许一个核账在跑，重复触发会被跳过（避免限流和记录互相覆盖）。

## 六、直播录制

- 检测到开播后按「录制画质」档位录制，默认「原画」（平台原画，多数 720p，部分 1080p）
- 部分直播间提供「源画质」，有则优先
- 录制是 FLV 直录，结束后纯 Python 重封装为 MP4（**不转码，画质与源一致**）
- 文件：`data\直播录像\<昵称>_<日期时间>_原画.mp4`
- 直播结束后状态自动从「直播中」回到「监控中」

## 七、数据目录

默认在程序目录下的 `data\`，可在设置 → 数据与维护 → 打开数据目录 查看：

```
data\
├─ Volume\
│  ├─ settings.json          Cookie（抖音 / TikTok）
│  ├─ Download\              默认下载目录
│  └─ 历史下载\              按账号归档
├─ 直播录像\                 录屏 MP4
└─ 下载记录.json             作品是否已下载的水位
```

**换机器**：整个程序目录（含 `data\`）拷过去即可，账号、记录、作品都在。

**注意**：`data\` 里有 Cookie，等于登录凭据，不要共享或上传。

## 八、常见问题

**新作品没下载？**
先看「运行动态」有没有「接口限流」或「出错」。限流时程序会自动退避，等一会儿；持续出错多半是登录态失效，重新扫码。

**日志说「未检测到发布新作品」但主页明明有新视频？**
新视频可能是「仅自己可见」或审核中，接口拿不到；也可能是隐私设置。用「诊断作品计数…」看接口与主页差多少。

**历史作品显示缺，但文件夹里明明有？**
点右键「核账历史作品」跑一次，会把本地已有文件补进下载记录（不重下）。

**录屏音画不同步？**
新版本已按音频包真实时间戳写时长；旧文件无法精确修复，可重新录制。

**磁盘满了？**
设置 → 数据与维护 → 自动清理…，或手动删 `历史下载` 里不要的作品；程序会在剩余空间低于阈值时暂停下载。

**同时开了两个？**
程序是单实例，第二个会直接退出并提示。
